# 马原毛概在线刷题

这是一个纯前端刷题网站。

## 已包含功能

- 毛概题库、近代史题库与马原题库切换
- 单选题和多选题
- 答案判断与详细解析
- 上一题、下一题、随机一题
- 题干、选项、来源和解析全文搜索
- 错题本
- 已答题数、正确数、正确率统计
- 45分钟与 60秒限时练习
- 自定义 JSON 题库导入
- 学习记录导出与导入
- 附赠100道算术题题库

注：题库仅供参考，如有错误，欢迎及时反馈。

## 数据保存说明

答题记录、错题本、自定义题库和主题设置均保存在浏览器 `localStorage` 中：

- 同一浏览器再次访问时会自动保留。
- 清理浏览器数据后可能丢失。
- 不同浏览器或不同设备不会自动同步。
- 建议定期使用“导出学习记录”备份。
